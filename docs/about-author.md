# About the Author

**Ahmed Awad** — known online as **NullC0d3** — is a security researcher, Red Team operator, and open-source developer.

## Background

Ahmed has been active in the security community since 2018, with experience spanning:
- Red Team operations
- Bug bounty hunting on major platforms (HackerOne, Bugcrowd, Intigriti)
- Vulnerability research and disclosure
- Open-source security tool development

## Philosophy

> "Security tools should be open by default, safe by design, and explainable in their findings. HunterX was built to prove that AI-assisted scanning can be both powerful and responsible."
