# V6 Archive

**HunterX v7 is the current architecture. v6 is archived here for historical
reference only and is NOT part of the active product.**

This directory contains the retired HunterX v6.0.0 material:

- `docs/` — v6 documentation pages (API, CLI, modules, features, reasoning
  engine, skills framework, plugin development, Docker guide, and reports).
- `source/` — the retired v6 flat Python package (`hunterx/`, `api/`, `core/`,
  `plugins/`, `payloads/`) preserved for reference. It is not packaged,
  installed, tested, or referenced by v7.
- `tests/` — the retired v6 unit tests (kept with the v6 source).
- `hunterx.yaml` — the retired v6 configuration file.

Nothing here is loaded at runtime by HunterX v7. For current documentation see
[`../documentation.md`](../documentation.md) and the `docs/` guides for the v7
platform.

Historical references to v6 inside this archive are intentional and are not to
be treated as current product behavior.
