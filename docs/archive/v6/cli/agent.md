deploy, monitor, and manage autonomous agents that perform various security tasks.## Syntax```bashhunterx agent [SUBCOMMAND] [OPTIONS]```## Subcommands| Subcommand | Description ||------------|-------------|| `list` | List all available agents and their status || `deploy` | Deploy one or more agents to perform tasks || `status` | Check the status of running agents || `stop` | Stop one or more running agents || `logs` | View logs from specific agents || `config` | Configure agent behavior and settings |## Examples### List All Agents```bashhunterx agent list```Sample output:```Available Agents:  recon       : Reconnaissance Agent (IDLE)  vuln        : Vulnerability Assessment Agent (IDLE)  exploit     : Exploitation Agent (IDLE)  persist     : Persistence Agent (IDLE)  lateral     : Lateral Movement Agent (IDLE)  exfil       : Exfiltration Agent (IDLE)  report      : Reporting Agent (IDLE)  cleanup     : Cleanup Agent (IDLE)```### Deploy Agents```bashhunterx agent deploy recon vuln exploit```### Check Agent Status```bashhunterx agent status```Sample output:```Agent Status:  recon       : RUNNING (Target: 192.168.1.0/24, Progress: 45%)  vuln        : IDLE  exploit     : RUNNING (Target: 192.168.1.10, Progress: 20%)  persist     : QUEUED  lateral     : QUEUED  exfil       : QUEUED  report      : WAITING_FOR_DATA  cleanup     : INACTIVE```### View Agent Logs```bashhunterx agent logs exploit --follow```### Stop Specific Agents```bashhunterx agent stop exploit persist```### Stop All Agents```bashhunterx agent stop --all```## Agent Types| Agent | Description ||-------|-------------|| **recon** | Performs reconnaissance: port scanning, service enumeration, subdomain discovery || **vuln** | Conducts vulnerability assessments using signature-based and heuristic detection || **exploit** | Attempts to exploit identified vulnerabilities (requires authorization) || **persist** | Establishes and maintains persistent access to compromised systems || **lateral** | Moves laterally within networks using harvested credentials and vulnerabilities || **exfil** | Extracts sensitive data from compromised systems || **report** | Generates comprehensive reports from collected data || **cleanup** | Removes artifacts and restores systems to pre-test state |## Common Options| Option | Description ||--------|-------------|| `--target` | Specify target(s) for the agent (IP, CIDR, domain, URL) || `--mode` | Operation mode (passive, active, aggressive) || `--priority` | Execution priority (low, normal, high) || `--timeout` | Maximum execution time in minutes || `--output` | Output format for results (text, json, xml) || `--tag` | Custom tag for grouping related operations |## Typical Workflow1. **List Agents**: Review available agents and their current status2. **Select Agents**: Choose the agents needed for your objective3. **Define Targets**: Specify the target(s) for the operation4. **Deploy Agents**: Launch the selected agents with appropriate parameters5. **Monitor Progress**: Use `status` and `logs` to track execution6. **Handle Results**: Collect reports, evidence, and artifacts7. **Cleanup**: Run the cleanup agent to remove any traces of testing## Related Commands- `hunterx workflow` - Create automated workflows that use multiple agents- `hunterx reasoning` - Configure the AI that directs agent behavior- `hunterx scan` - Execute scans that may trigger agent deployment- `hunterx agent config` - Adjust global agent settings## Common Errors- **Agent Already Running**: Stop the agent first before redeploying- **Invalid Target**: Verify target format (IP, CIDR, domain, etc.)- **Insufficient Privileges**: Some agents require elevated permissions- **Resource Exhaustion**: Too many agents running simultaneously may cause performance issues## Best Practices- Start with reconnaissance agents before deploying more invasive ones- Use tagging to group related operations for easier tracking- Monitor resource usage when running multiple agents simultaneously- Always have the cleanup agent ready to run after testing- Document agent deployments and objectives for audit trails- Test agent configurations in a lab environment before production use
