installing HunterX, verify that the CLI is accessible by running:```bashhunterx --version```You should see output similar to:```HunterX v6.0.0```If you see a "command not found" error, refer to the [Installation Guide](/installation/) to ensure HunterX is properly installed and your PATH is configured correctly.## Checking HelpTo see all available commands and options, run:```bashhunterx --help```This will display the help menu, which includes:- List of all available commands- Global options (e.g., `--verbose`, `--output`)- Subcommand-specific help## Updating the CLITo update HunterX to the latest version:### Via Pip```bashpip install --upgrade hunterx```### Via Docker```bashdocker pull hunterx/hunterx:latest```### Via Source```bashcd HunterXgit pullpip install -r requirements.txt```## Troubleshooting InstallationCommon installation issues and their solutions:### "hunterx: command not found"- Ensure the Python Scripts directory is in your PATH- On Windows: `%APPDATA%\Python\Python3x\Scripts`- On Linux/macOS: `$HOME/.local/bin` (if installed with `--user`)- Restart your terminal after installation### Permission Errors- Avoid using `sudo pip` on Linux/macOS- Use a virtual environment or the `--user` flag instead- On Windows, run your terminal as Administrator### Version Mismatch- If you see an unexpected version, you may have multiple installations- Use `which hunterx` (Linux/macOS) or `where hunterx` (Windows) to locate the executable- Ensure only one version is installed and in your PATH## Next Steps- Explore the [Command
