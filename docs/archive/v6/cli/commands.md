Each category contains related commands for specific tasks.## Command Categories| Category | Description | Commands ||----------|-------------|----------|| **Scanning** | Network and vulnerability scanning | `scan`, `module` || **Agents** | Autonomous agent control | `agent` || **Workflow** | Workflow automation | `workflow` || **Reasoning** | AI reasoning and planning | `reasoning` || **Skills** | Skill execution | `skills` || **Knowledge Graph** | Knowledge graph operations | `knowledge-graph` || **Payload** | Payload generation | `payload` || **Report** | Report generation | `report` || **Configuration** | Configuration management | `config` || **Maintenance** | Updates and diagnostics | `update`, `doctor` || **Utilities** | Help and version | `--help`, `--version` |## Getting HelpFor detailed information about any command, use the `--help` flag:```bashhunterx <command> --help```Example:```bashhunterx scan --help```## Common OptionsSeveral options are available across multiple commands:- `--output <format>`: Specify output format (json, yaml, txt)- `--verbose`: Enable verbose logging- `--quiet`: Suppress non-essential output- `--config <file>`: Specify a custom configuration file- `--no-color`: Disable colored output## Command Categories in Detail### Scanning CommandsThe `scan` command is the primary entry point for initiating security assessments. It orchestrates reconnaissance, vulnerability assessment, and optional exploitation based on the selected modules.### Agent CommandsManage and monitor HunterX's autonomous agents that execute specific tasks during an assessment.### Workflow CommandsDefine and execute automated workflows that combine multiple scanning and penetration testing steps.### Reasoning CommandsInteract with HunterX's AI reasoning engine to analyze results, generate hypotheses, and adapt assessment strategies.### Skills CommandsExecute individual security skills (e.g., port scanning, vulnerability checks) outside of a full scan workflow.### Knowledge Graph CommandsQuery and manage the knowledge graph that stores discovered assets, vulnerabilities, and relationships.### Payload CommandsGenerate, customize, and manage exploit payloads for various targets and vulnerabilities.### Report CommandsGenerate professional reports in various formats (HTML, PDF, JSON, XML) from scan results.### Configuration CommandsView, edit, and manage HunterX configuration settings.### Maintenance CommandsKeep HunterX up-to-date and diagnose issues with `update` and `doctor`.## Related Resources- [Command Examples](/cli/examples/) - Practical usage examples- [Installation](/cli/installation/) - Verify and manage your CLI installation- [Features](/features/) - Explore HunterX capabilities- [Use Cases](/use-cases/) - Real-world applications
