## GitHub Issues

Use [GitHub Issues](https://github.com/nullc0d30/HunterX/issues) for:

- Bug reports (with reproduction steps and logs)
- Feature requests (with use case descriptions)
- Documentation issues (missing or incorrect content)

Before opening an issue, search existing issues to avoid duplicates. Use the provided issue templates.

---

## GitHub Discussions

Use [GitHub Discussions](https://github.com/nullc0d30/HunterX/discussions) for:

- Questions about usage or configuration
- Ideas and feature brainstorming
- Community support and knowledge sharing
- Show and tell (share your skills, workflows, or integrations)

Discussions are community-driven. While maintainers participate, responses from the community are welcome and encouraged.

---

## Security

Report security vulnerabilities via [GitHub Private Vulnerability Reporting](https://github.com/nullc0d30/HunterX/security/advisories/new).

**Do not** open public issues for security vulnerabilities. See [SECURITY.md](https://github.com/nullc0d30/HunterX/blob/main/SECURITY.md) for the full security policy.

---

## Commercial Support

Commercial support and sponsorship are available via [GitHub Sponsors](https://github.com/sponsors/nullc0d30).

Sponsorship helps fund:

- Ongoing maintenance and development
- Infrastructure and CI/CD costs
- Security audits
- Community events and sprints

Sponsors may receive priority support, advisory access, and recognition in release notes.

## Response Times

| Channel         | Response Time | Responsibility |
|-----------------|---------------|----------------|
| Security        | Within 72 hours | Maintainers  |
| Bug reports     | Within 1 week | Maintainers    |
| Feature requests| Within 2 weeks | Maintainers   |
| Discussions     | Community-driven | Community + Maintainers |

Response times are targets, not guarantees. Maintainers volunteer their time and respond as availability allows. The community is encouraged to help answer questions in Discussions.
